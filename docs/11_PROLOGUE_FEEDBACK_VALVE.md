# 인트로와 1장 피드백·밸브 장착

2026년 10월 4일 사용자 요청에 따른 최신 제작 기준이다. [인트로 원문](../data/prologue.json), [1장 퍼즐](../data/ch01.puzzles.json), [장면 좌표 계약](../art/production/v01/ch01-render-contract.json)을 수정 원본으로 사용한다.

## 도윤이 창고에 도착하기까지

인트로는 네 장면, 대사 13개다. 도윤의 신원과 회사 경력은 알고 있으며, 과거 사건의 판단과 납치 이후 이동 기억 일부가 불분명한 상태다. 납치범의 정체나 범행 동기, 과거 책임의 결론은 앞당겨 공개하지 않는다.

| 장면 | 내용 | 배경 |
| --- | --- | --- |
| 익명의 메시지 | 퇴근 전 8년 전 연무도 보고서의 제출 전 원본을 보여 주겠다는 연락을 받는다. 입사 첫해 맡았던 일이며, 보관 경위를 확인하려 다음 날 만남에 응한다. | PROLOGUE_OFFICE_V01 |
| 항구의 약속 | 오후 6시 30분, 불이 켜진 항구 사무실 앞에서 상대를 찾는다. 승합차로 다가가던 중 뒤에서 팔을 붙잡혀 차 안으로 밀려 들어간다. 충격 뒤 의식이 끊기며 얼굴은 확인하지 못한다. | PROLOGUE_PORT_V01 |
| 끊어진 기억 | 엔진 소리, 흔들림, 창 너머 물빛, 철문과 의자가 파편적으로 기억난다. 이동 목적지는 알지 못한다. | PROLOGUE_BOAT_V01 |
| 낯선 천장 | 빛이 들어오는 창고에서 깨어나 손목의 끈을 느낀다. 기존 D01_001과 스피커 방송으로 이어진 뒤 결박 해제 탐색을 시작한다. | CH01_R01_A 재사용 |

시간 간격은 전날 사무실 → 다음 날 저녁 항구 → 밤중 이동 → 창고에서 각성이다. 환각이나 전면적 기억 상실로 사건을 설명하지 않는다. 익명 제안, 차 안으로 강제 이동, 운송 중 의식이 돌아오는 단편으로 납치 상황을 보여 준다. 범죄 수법의 상세 설명이나 잔혹한 장면은 넣지 않는다.

## 그래픽과 읽기 UI

새 배경 세 장은 내장 image_gen으로 제작한 1024×1536 PNG이며 [제작 로그와 전체 프롬프트](../art/production/v01/prologue-generation-log.json)에 출처를 저장했다. 원본은 `art/production/v01/story/prologue`에 보존하고 웹 빌드에서 WebP를 만든다. 현대 반실사 2D, 건조한 재질, 약한 사용 흔적, 석양과 푸른 바닷빛이 기준이다. 그림에는 읽어야 하는 한글이나 기능 버튼을 굽지 않는다.

인트로는 전 화면 그림, 상단 PROLOGUE·건너뛰기, 장면 시간·제목과 네 칸 표시, 하단 대사 패널과 설정으로 구성한다. Pretendard와 사용자 대화 글자 크기·밝기·타자 효과 설정을 사용한다. 다음 대사는 탭으로 진행하며 자동으로 넘어가지 않는다. 타자 효과 사용 시 첫 탭은 전문, 다음 탭은 다음 대사다. 이어하기 안내는 하단에 표시해 장면 제목을 가리지 않는다.

## 진행과 저장

`GameState.dialogueQueue`에 D00_001~013을 기존 D01 대사 앞에 추가한다. 새 별도 저장 형식을 만들지 않는다. 각 대사 진행 후 자동 저장하며 재접속하면 같은 장면과 같은 대사에서 계속된다. `skipPrologue`는 남은 인트로 대사만 읽음 처리하고 기존 감금실의 첫 대사에서 멈춘다. 건너뛴 내용도 대화 수첩에서 다시 읽을 수 있다. 기존 저장은 그대로 수용하며 진행 중이던 사용자에게 인트로를 강제로 삽입하지 않는다. 처음부터 감상하려면 새 게임을 시작한다.

## 최초 성공과 재조사 문구

기존 1장의 `attempt`가 성공에도 `repeatText`를 사용하던 문제를 고쳤다. 25단계 모두 `successText`를 별도로 갖는다. 첫 금속 조각 획득은 ‘금속 조각을 챙겼다.’, 예비 퓨즈는 ‘예비 퓨즈를 챙겼다.’로 표시한다. 완료된 대상의 재조사는 기존 `repeatText`를 사용하며 새 아이템을 지급하지 않는다. 장치 개방·조합·설치·배수도 실제로 방금 실행한 행동을 설명한다. 2~10장은 이미 성공과 중복 처리가 분리되어 있다.

## 설비실 가운데 손잡이

R03_B의 장착 손잡이 레이어는 P21 완료 시만 나타난다. 실제 배경 축 중심은 약 (0.519, 0.350)이다. 레이어 rect를 x=0.455, y=0.294, w=0.13, h=0.108333으로 수정했다. 5:6 장면에서 원본 정사각형 손잡이가 정사각형으로 표시되며, 투명 여백을 포함한 허브 중심이 밸브 축에 맞는다. 화면 채우기와 전체 장면 보기는 배경·레이어·핫스폿에 같은 변환을 적용한다. 배수 전·후 전체 배경의 축 위치도 동일하다.

완료 후 장치 재조사 시 바다 유입 닫힘 / 저수 연결 닫힘 / 배출 열림으로 표시한다. P21에서 손잡이는 인벤토리에서 소모되고 설비에 남는다. 게임·팝업 상단바의 metal-frame.svg 배경도 모두 제거했다.

## 확인 범위와 제작용 화면

12개 단위 검사에 인트로 13대사 저장 복원·건너뛰기·기존 저장 수용과 25단계 최초 성공/재조사를 추가했다. `tests/e2e/prologue-and-feedback.mjs`는 320×568, 360×780, 390×844, 1280×900에서 네 인트로 장면의 글꼴·버튼 크기·가시성, 손잡이 허브 위치와 완료된 밸브 상태를 확인한다. 실제 시작·새로고침·건너뛰기·첫 아이템 문구도 확인한다. 1장 25단계 전체 진행과 챕터 2 전환을 다시 통과했다.

인트로 네 장면과 손잡이 장착 화면은 `ui-preview.html?screen=intro-office&focus=1`, `intro-port`, `intro-boat`, `intro-awake`, `valve-installed`로 제공한다. 최신 UI 납품은 기본 77장과 전체 스크롤 18장, 총 95장의 [PNG 갤러리](../art/ui-screens/season-v02/gallery.html)다. 원본 그래픽은 PNG 134장이다. 실제 Android·iOS 기기 검수와 음성 연기는 현재 확인 범위에 포함되지 않는다.
