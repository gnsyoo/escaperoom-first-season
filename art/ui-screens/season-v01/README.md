# 2장부터 10장 완성 UI 이미지

각 장의 탐색, 인물 대화, 확대 퍼즐, 인벤토리, 수첩을 실제 React 화면에서 내보냈다. 공통 홈·지도·설정·원본 자료·힌트와 세 엔딩을 포함한다. 기본 PNG 53장과 전체 스크롤 PNG 13장이다. 전 화면 Pretendard Variable. 이전 1장 화면 v02는 그대로 보존한다. 제작용 스포일러가 포함된다. 추가 검증은 사용자 요청에 따라 생략했다.
